What is HTML?

HTML Stands for Hyper Text Markup Language. and is a text-based language used to structure and display web pages.

HTML stands for Hyper Text Markup Language. HTML is the standard markup language for creating Web pages.

HTML describes the structure of a Web page. HTML consists of a series of elements. HTML elements tell the browser how to display the content.
